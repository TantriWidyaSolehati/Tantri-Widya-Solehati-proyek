# Analisis Nilai Siswa

## Deskripsi
Program Python sederhana untuk menganalisis nilai siswa.

## Fitur
- Input nilai siswa
- Menghitung rata-rata
- Menentukan nilai minimum
- Menentukan nilai maksimum
- Menghitung jumlah siswa lulus
- Menghitung jumlah siswa tidak lulus

## Persyaratan
- Python 3.x

## Cara Menjalankan

```bash
python main.py
```

## Struktur Folder

- main.py : Program utama
- input_data.py : Input pengguna
- proses.py : Logika perhitungan
- output.py : Menampilkan hasil
- tests/ : Dokumen pengujian
- docs/ : Screenshot program

60
